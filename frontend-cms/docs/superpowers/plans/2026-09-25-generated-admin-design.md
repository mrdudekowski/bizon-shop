# Перенос визуального языка генераций в BIZON

Запрос: воссоздать дизайн сгенерированных экранов в текущей админке. Основа — три сохранившихся изображения этой задачи: список шин, документ шины, направления.

Рабочий сценарий: пользователь открывает раздел, выбирает документ, редактирует данные и фотографию, сохраняет черновик; администратор отдельно публикует сохранённый документ. Источник состояния — существующий локальный AdminClient.

Визуальный контракт: графитовое меню шириной 236px, жёлтый акцент, светло-серый холст, белые поверхности, компактные таблицы, горизонтальная навигация по блокам, липкая нижняя панель сохранения. Эта тема заменяет старую бело-мятную спецификацию по новому запросу пользователя.

Порядок работы:
1. Обновить токены и общую оболочку, активные разделы и роли.
2. Привести списки шин, направлений, дисков, Shop, страниц, материалов и пользователей к единой системе.
3. Оформить документы, навигацию по блокам, фото с фокусом и рамкой кадра, нижние действия.
4. Проверить сборку, типы, линтер и браузерные сценарии на широком и узком экране.

Данные и черновики сохраняются в существующем формате. Декоративные заказы, аналитика и прочие выдуманные генератором разделы не переносятся. Новых серверных функций этот проход не добавляет.
