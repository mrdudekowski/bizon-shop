# Локальный E2E для загрузки медиа CMS

Сценарий поднимает отдельные локальные процессы backend и CMS, проверяет их против тестовой PostgreSQL-копии и локального S3-совместимого хранилища, затем запускает браузерный путь загрузки и публикации.

## Однократная настройка

1. Убедитесь, что доступны изолированная БД, восстановленная локально как `default_db_e2e`, и локальный MinIO с отдельным бакетом `bizon-cms-e2e-20261021`.
2. Скопируйте `environment.example.json` в корень репозитория под именем `.cms-media-e2e.local`.
3. Заполните там только локальный пароль PostgreSQL, локальные ключи MinIO и пароль учётной записи `@local.test` в этой E2E-копии. Файл `*.local` игнорируется Git.
4. Установите браузер Playwright, если Edge недоступен: `npm run test:e2e:install`. На Windows по умолчанию используется установленный Microsoft Edge; другой Playwright channel можно указать через `CMS_MEDIA_E2E_BROWSER`.

## Запуск

Из корня репозитория выполните:

```powershell
npm run test:e2e:cms-media
```

Сценарий проверяет вход, отказ усечённого PNG без записи в медиа-библиотеку, загрузку валидного PNG, наличие совпадающих байтов в S3, выбор того же файла из галереи, сохранение и повторное открытие черновика, публикацию в локальную БД, snapshot API и статическую сборку сайта с совпадающими ревизией, SHA-256 и байтами файла.

Перед стартом проверяются loopback-хосты PostgreSQL и S3, имя БД и бакета для E2E, наличие CMS-таблиц и доступность бакета. Backend запускается без `.env` и получает только проверенную локальную DB/S3-конфигурацию; ключи Timeweb и публичный production origin очищаются. Браузер блокирует внешние HTTP(S)-запросы. При любом несовпадении preflight завершает тест до запуска приложения.

Публикация выполняется только в `default_db_e2e`. После проверки сценарий восстанавливает исходный снимок главной страницы и удаляет тестовый медиа-объект. Статическая сборка изолированной E2E-базы нужна только для проверки; исходные локальные каталоги `out/` и `.content-snapshot-previous/` сохраняются и восстанавливаются. Боевые сервисы и БД не используются.
